ImplicitArrays.jl

The ImplicitArrays.jl package provides interaction matrices for the Julia programming language.

In a nutshell

An interaction matrix M of size n × m consists of row elements rᵢ, column elements cⱼ, and an interaction function f such that Mᵢⱼ = f(rᵢ, cⱼ). The matrix is stored implicitly: only the row elements, column elements, and interaction function are kept, while individual entries are computed on demand.

julia> using ImplicitArraysjulia> M = InteractionMatrix{Int}([1, 2, 3], [10, 20, 30], +)3×3 InteractionMatrix{Int64}: 11  21  31 12  22  32 13  23  33

Custom interaction functions are ordinary callable types:

julia> struct DivFun <: InteractionFunction{Int, Int, Float64} endjulia> (::DivFun)(x::Int, y::Int) = x / yjulia> InteractionMatrix([10, 20, 30], [5, 2, 1], DivFun())3×3 InteractionMatrix{Float64}: 2.0   5.0  10.0 4.0  10.0  20.0 6.0  15.0  30.0

Learn more

See the Interaction matrices page for a detailed guide, more examples, indexing, views, and the full API reference.

Deprecated types

The legacy BlockMatrix, FixedValueArray, RowProjectionVector, and RowProjectionMatrix types are deprecated and retained for backward compatibility only. See Historic types for details and recommended replacements.

Installation

In the Julia REPL, switch to the Pkg mode by pressing ] and enter the following command:

pkg> add ImplicitArrays

InteractionFunction{R, C, T}

Abstract base type of all interaction functions R × C → T.

InteractionMatrix{T, R, C, F <: InteractionFunction{R, C, T}} <: AbstractArray{T, 2}

Interaction matrix with elements of type T, generated from row elements of type R, column elements of type C, and an interaction function F: R × C → T.
